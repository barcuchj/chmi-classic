# Podklady a původ

Rozšíření není oficiálním produktem Českého hydrometeorologického ústavu a není s ČHMÚ spojeno.

## Použité referenční zdroje

- Současná radarová aplikace ČHMÚ: <https://produkty.chmi.cz/radar/>, ověřeno 4. 9. 2026.
- Archivní vzhled původního nowcasting portálu: <https://web.archive.org/web/20260816180503/https://intranet.chmi.cz/files/portal/docs/meteo/rad/inca-cz/short.html>, snímek z 16. 8. 2026.
- Současný animovaný prohlížeč Meteosat: <https://produkty.chmi.cz/druzice/>, ověřeno 4. 9. 2026.
- Archivní prohlížeč MSG: <https://web.archive.org/web/20260210150546/https://intranet.chmi.cz/files/portal/docs/meteo/sat/data_jsmsgview.html>, snímek z 10. 2. 2026.
- Archivní prohlížeč polárních družic AVHRR: <https://web.archive.org/web/20260614095513/https://intranet.chmi.cz/files/portal/docs/meteo/sat/data_jsavhrrview.html>, snímek z 14. 6. 2026.
- Současné stránky polárních družic: <https://www.chmi.cz/namerena-data/polarni-druzice/true-color>, ověřeno 4. 9. 2026.
- Uživatelem dodaný výřez přepínače `Dle okna / Zoom 4x / Web Maps`.
- Apple: balení a spuštění Safari Web Extension: <https://developer.apple.com/documentation/safariservices/packaging-a-web-extension-for-safari>, ověřeno 4. 9. 2026.

## Způsob použití

Referenční zdroje byly použity k popisu rozmístění a chování ovládacích prvků. Rozšíření neobsahuje kopii HTML, JavaScriptu, CSS, obrázků, loga ani meteorologických dat ČHMÚ nebo Internet Archive. Přidává lokální ovladače, které volají původní prvky živých stránek ČHMÚ, a upravuje pouze jejich rozložení v uživatelově prohlížeči.
